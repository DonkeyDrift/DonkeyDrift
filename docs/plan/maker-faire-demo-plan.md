# Maker Faire 深圳现场演示方案（2 人精简版）

- 制定日期：2026-09-11（v2，替代 v1 完整版）
- 前提：现场 **2 人**；主角为自动漂移展示；合作目标覆盖教育/硬件/企业/媒体
- 原则：**演示自动化、互动单线程、留资全自助——做不到这三条的，全部砍掉**

---

## 一、战略：一个主角 + 一条线 + 一套自动化

### 主角：整点漂移秀（15 分钟/次，一天 4-6 次）

自动漂移 30 秒 + 大屏实时 β/航向曲线 + 观众按键触发起漂。这是全场唯一差异化，是流量、传播、合作的共同入口。

### 互动线：驾驶体验 → 数据体检（全馆唯一体验点，同一台笔记本）

观众开 60 秒车（自动录制）→ 一键生成"你的驾驶数据健康吗"报告。**一个动作完成互动 + 教育展示 + 留资引导**，不需要第二个体验点。

### 自动化三件套（没有这三件，2 人必崩）

1. **`demo.sh` 一键启动**：自检（相机/串口/标定/电量）→ 拉起 Web UI + 漂移引擎 → 大屏就绪；
2. **预录演示视频**：电视循环播放，设备故障时摊位不冷场，人也腾得出手；
3. **扫码自助留资**：表单 + 贴纸/明信片自取，人完全不用管。

---

## 二、2 人怎么转（每日运转模型）

| 时段 | 内容 | A（表演/讲解） | B（洽谈/物料） |
|---|---|---|---|
| 开场 10 分钟 | pre-flight 自检 | 双人一起 | 双人一起 |
| 整点 :00 | 漂移秀 15 分钟 | 主操 + 喊麦 | 引流 + 拍竖版视频 |
| 其余时间 | 开放体验 | 主讲解 + 看设备 | 洽谈 + 补物料 |
| 每小时 | 轮换 | A ↔ B | A ↔ B |
| 收摊 15 分钟 | 复盘、线索分级 | 双人一起 | 双人一起 |

**两条铁律**：

1. **只对预约者深谈**（展前约好时段的合作方/媒体），散客一律"一页纸 + 扫码"，不占演示人力；
2. **一人独挡**：话术背熟两档（30 秒电梯版 / 2 分钟演示版），任何一人随时可独立完成演示 + 接待。

## 三、三个月只做三件事（按优先级）

### P1 · 演示稳定化（第 1 个月）—— 最高优先级
- `demo.sh`（自检 → 启动 → 自动恢复）+ pre-flight 每日 10 分钟；
- 备件：ESP32 / 舵机 / 电池 ×2 / 相机 / 整车——**这是最值得花的钱**；
- 展前踩点标定（场地单应性存 npz，仓库已有 `field_homography.npz` 先例）；
- 彩排 3 次 + 故障演练（拔相机 / 撞车 / 人流爆满）。

### P2 · 体验闭环 MVP（第 1-2 个月）
- 驾驶体验自动录制 + 数据体检报告（任务单 v1 范围，约 4-5 周）；
- **砍掉**：排行榜、大屏专页、SSE 推送（→ v2）；大屏 = 笔记本投电视；
- 3 条预录示例数据（健康 / 左右失衡 / 直行过多）兜底——任何时刻都能演示体检。

### P3 · 传播与合作（第 2-3 个月）
- 视频 3 条：30 秒高光 / "为什么模型学不会漂移"技术故事 / 失败花絮；
- **预约制**：媒体 + 四类合作方各约 2-3 家，现场只服务预约；
- 物料定稿：一页纸 + 表单 + 名片。

---

## 四、合作：一页纸 + 预约制 + 48h 跟进

- **物料只有 1 件**：A4 三折页（项目一页 + 四类合作模式四格 + 二维码）；
- 现场只做 3 个动作：递一页纸 → 扫码/加微信 → 线索表当场分级（A 明确意向 / B 感兴趣 / C 围观）；
- 展后 48h：A/B 级逐一跟进（模板邮件：教育给"试点合作书"、厂商给"参考设计意向书"、企业给"内训试讲邀请"、媒体给"素材包"）；1 周发 recap。

## 六、风险 Top 5（各配一句预案）

| 风险 | 预案 |
|---|---|
| 漂移失败 / 车撞毁 | 围栏 + RC 夺回；备件整车 3 分钟换；预录视频兜底 |
| 设备故障 | demo.sh 自动恢复 + 硬件双份 + pre-flight 提前发现 |
| 人流爆满 | 体验限时 60 秒/人 + 排队区自助留资 |
| 人流稀少 | 整点秀时刻表主动造场 + 预约时段填场 |
| 洽谈占演示人力 | 预约制 + 自助留资（第 2 章铁律） |

---

## 七、KPI（只考核 4 个）

1. 演示无故障运行率 ≥ 95%；
2. 深度体验（完成驾驶+体检）≥ 150 人次/天；
3. 留资 ≥ 60/天，其中 A/B 级线索 ≥ 8；
4. 展后 1 个月实质合作意向 ≥ 2。

---

## 八、与开发任务单的关系

- 数据体检开发任务单（`docs/plan/health-check-interactive-dev-tasks.md`）**v1 范围 = P2**：只做 后端分析 API + 体验模式 + 报告卡片 + 示例数据；大屏专页/排行榜/SSE 全部降级为 v2；
- `demo.sh` 细化归 P1（演示稳定化），两线并行、录制链路稳定后启动体验闭环。
