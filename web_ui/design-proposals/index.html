点击任意卡片打开对应设计稿（静态 HTML，1440×900 桌面布局为主，兼容移动端）

方案 A

赛车座舱 HUD

深色技术风，荧光青 + 琥珀色，等宽数字遥测，切角面板，视频为绝对主角。强调驾驶时的 glanceability，密度最高，适合「操控优先」。

 方案 B

Apple Pro 消费级

现有 Apple 浅色风的精致化升级：毛玻璃、大圆角、分层柔和阴影、渐进披露。最克制优雅，学习成本最低，适合「面向更广用户」。

 方案 C

开发者工具 · Linear 风

中性深色 + 左侧边栏 + ⌘K 命令面板，13px 紧凑密度，键盘优先，工业级高效。适合「高频专业用户 / 工程师日常」。

 方案 D · 推荐组合

HUD 布局 × Apple 材质

A 的三栏座舱布局（视频主角 + 双侧仪器 + 事件日志），换上 B 的浅色 Apple 材质：白色卡片、大圆角、柔和阴影、蓝色主行动。密度与优雅兼得。
